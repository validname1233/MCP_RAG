**覆盖**：44 题覆盖 25/50 篇 pdf，10 组同文多侧面设计（烯效唑×3、AI 落地×3、调环酸钙×2、呋虫胺×2 等）对块级评测友好；97 篇 md、10 个 xlsx 语料零覆盖（gold 全 pdf，与既定范围一致，后续可补）。snippet 锚点工艺整体很高：42/44 为纯中文连续段，数字/英文/符号（PEST、ASP、50-200μm、73.53%）系统性地被留在锚点外，多条 note 记录了高频词弃用与断行规避的决策过程，可复核性好。

**系统性风险**（按优先级）：
1. **本地坏提取文档在 MinerU 上线后"复活"会改变检索格局**：16/50 篇 pdf 本地中文占比 <20%（师建玲、罗文慧、孟英、三篇 GCP、李东、魏继刚、马颖等扫描件）。当前所有"全库唯一"结论是在这 16 篇不可见的前提下成立的；上线后 GCP 三篇、黄连两篇、多抗霉素家族会重新参与竞争。**建议 MinerU 入库后重跑本报告的批量验证脚本**（尤其是同主题家族：氰霜唑×4、调环酸钙×3、多抗霉素×5、GPC×3）。
2. **同题双答案（gold 不完备）**：Q43（郭恒文同答三唑对比且拼写更佳）是唯一实质案例，Q6/Q11/Q29/Q36 是程度较轻的召回竞争。query 中心的 gold 标注在"多文档均可回答"时要么 exact 化、要么 gold 数组放开，否则会把正确召回误判为 miss。
3. **MinerU 文本形态迁移**：断行/空格/表格序列化方式与 pdf-parse 不同。受影响最大的是依赖断行位置截取的锚点（Q28 半句、Q13 标题形态、Q1 断行起点）与扫描风格文档（Q43 冯已、Q9 尹清）。现有"入库预检器兜底"的安排是对的，建议把 44 条 snippet 预检做成入库流水线的固定步骤。
4. Q41 类"清单词当分类答案"的结构性错误提醒：以列举页为锚点时需确认该词确实处于 query 所断言的结构位置（分类/归属/顺序），仅词出现≠断言成立。
